# GDPR

isotope13 LLC is a US company with no EU establishment.

We are a **processor** for our customers' accounts and API requests, under our [DPA](../legal/DPA.md). We are a **controller** for everything else, under our [Privacy Policy](README.md): billing, uploads, verdicts, correspondence, and API requests made without a customer token.

| --- | --- |
| Notice and records of processing (Art. 13, 14, 30) | [Privacy Policy](README.md) |
| Processor terms (Art. 28) | [DPA](../legal/DPA.md) |
| Annex I: description of processing | [DPA, Scope](../legal/DPA.md#scope-annex-i) |
| Annex II: security measures (Art. 32) | [Security Measures](../security/README.md) |
| Annex III: subprocessors | [Approved Subprocessors](SUBPROCESSORS.md) |
| International transfers (Chapter V) | [DPA, Transfers](../legal/DPA.md#transfers): Standard Contractual Clauses |
| Breach notification (Art. 33–34) | [Incident Response Plan](../security/INCIDENT-RESPONSE.md) |
| Impact assessment (Art. 35) | [DPIA](DPIA.md) |
| Data flows | [API Architecture](../security/ARCHITECTURE.md) |
| EU and UK representative (Art. 27) | None. Exempt under Art. 27(2): business-to-business processing of account identifiers and an unlogged IP address, with no special-category data, is unlikely to put anyone at risk. |
